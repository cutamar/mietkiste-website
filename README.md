# mietkiste.ch

Static website for Mietkiste (equipment rental, region Brugg).

- Edit content in `build.py`, styles in `assets/style.css`.
- Build: `python3 build.py` (add `--domain` once mietkiste.ch points to GitHub Pages; this writes `docs/CNAME`).
- GitHub Pages serves the `docs/` folder from `main`.
